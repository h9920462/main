How to use

  1. Generate each pack as a 15-second video with any dark, still start image. The picture does not matter.
  2. Extract the audio. Lines are separated by about a second of silence, so each one is easy to find on the waveform.
  3. Each card says which of your 6-second clips each line goes over. Where one sentence covers two or three clips (for example S5a + S5b), it is spoken as one natural line: cut it at the pause after the word shown.
  4. If a pack mixes up the order or adds a voice, regenerate just that pack.
