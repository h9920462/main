2 · How to chain stills

  1. Generate the first still of each location run (for example @S1, @S14, @S31, @S52) from the character and location tags only.
  2. Save every finished still under its ID. When a prompt says "as in @S14" or "same position as @S1", attach that exact image as a reference along with the character tag. Reusing the image keeps the room, furniture and lighting identical from frame to frame.
  3. For split clips, generate the A still first, then feed it in to make the B close-up.
  4. Grade every still (section 3) before you animate it.
