How to use

  1. Work through the cards in order. Each card is one generation: make its start image with the image prompt, grade it as before, save it as Gxx_START.png, then paste the video prompt.
  2. Merged cards join several 6-second talking shots into one continuous take of up to 15 seconds. The video prompt lists each line with its timing. Set the length shown on the card, or generate 15 seconds and trim.
  3. Single cards are cutaways, close-ups and off-frame lines. Keep them short: set the length on the card if your tool allows, or trim in the edit.
  4. Image prompts that say "as in @S14" point to stills you have already made (S1–S17a). References to new stills use G numbers (for example "as in @G09"), so save each start image under its G number and attach it when a later prompt asks for it.
  5. In the edit, cut cutaways and close-ups into the long takes so the video keeps its cut every few seconds.
